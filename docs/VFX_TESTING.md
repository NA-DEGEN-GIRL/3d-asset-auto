# game-vfx 독립 세션 테스트

**한국어** | [English](VFX_TESTING.en.md)

스킬을 작성한 대화와 **별도의 새 LLM 세션**에서 실제 효과를 제작해 [game-vfx](../.agents/skills/game-vfx/SKILL.md)의 적용성을 확인합니다. 스킬 평가가 필요할 때 사용하는 안내이며, 일반 제작 요청마다 아래 보고 형식을 요구하지 않습니다.

## 새 세션에 줄 요청

버전 비교는 한 모델·한 작업을 기존 지침과 제안 지침의 독립된 새 세션에서 수행하는 것부터 시작합니다. 모델·설정, 동일한 영어 요청, 프로젝트·입력 스냅샷, 렌더러, 사용 가능한 제작·검토 도구와 시간·토큰·계산·비용 예산을 통제 가능한 범위에서 같게 유지하고 차이는 기록합니다. 스킬 진입점과 관련 연결 의존 문서는 revision 또는 내용 해시로 고정하고 실제로 읽은 참조를 기록하며, 프롬프트와 재생·캡처 도구 버전도 고정합니다. 현재 경로나 파일 수정 시각으로 과거 내용을 확정하지 않습니다.

아래 괄호는 사용자가 실제로 제공한 조건으로 채우고, 모르는 항목은 미정으로 두며 명시한 도구 선택은 유지합니다. 품질·스타일·출력 요구는 공개하되 다른 후보 결과, 알려진 수정법, 해결 코드, 정답 구현과 기대 판정은 넘기지 않습니다. 두 언어 안내 모두 아래 영어 템플릿을 그대로 사용합니다.

```text
$game-vfx Create [effect name and gameplay use] in this project.

Project: [folder, known engine/renderer/version; unspecified if unknown]
Effect: [required onset/travel/contact/end behavior and interactions; list each effect]
References: [supplied images/video/existing-effect paths and desired features]
Usage: [known device, camera, scale, background and concurrent-use conditions]
Quality: [readable form, timing, intensity, style and required level of finish]
Output: [formats and location; requested integration/preview, if any]
Budget: [authorized time/tokens, local compute/storage, paid calls and spending limit]

Read the project and linked skill, then make the effect for these conditions.
Do not edit the skill/shared documentation or publish outputs during this test.
```

상세 제작 지시서, 실패 분석, 정해진 검토 횟수나 검수·수정·보존 절차를 덧붙이거나 작업 중 별도로 상기시키지 않습니다. 그 행동이 스킬 자체에서 나오는지 시험하기 때문입니다. 아래 근거 목록은 작성 세션의 평가 항목이며, 제작 세션에 추가 프롬프트로 주입하지 않습니다.

제작 방식은 명시된 요구와 실제 조건에서 선택하게 합니다. 엔진이 미정이어도 요청한 출력 형식은 지킵니다. 예산 항목은 기존 요청과 사용자가 이 테스트에서 정한 허용 범위를 기록하며, 그 범위를 넘어선 유료 호출·업로드를 허용하지 않습니다. 실행 결과·캐시·참고·캡처는 스킬 소스와 분리한 고유 로컬 폴더에 보존하고 기존 결과를 덮어쓰지 않습니다.

## 작성 세션에 돌려줄 근거

작성 세션이 제작 기록과 산출물에서 효과별 근거를 확인합니다. 감독자의 미술 피드백 전 제출 결과를 보존하고 이후 도움을 받은 결과와 구분합니다. 설치 경로나 대리 캡처 같은 환경 지원은 미술 지도와 별도로 기록하며, 지원받은 실행은 완전 무개입으로 보지 않습니다. 최초 완성본은 기존 이력이나 제작에 간섭하지 않는 캡처에서 복구할 수 있을 때만 보존합니다. 불가능하면 테스트 요청에 보존 지침을 추가하지 말고 해당 단계를 미관측으로 표시합니다.

- 정확한 요청, 고정한 지침·의존 문서와 읽은 참조, 모델·설정, 재생·캡처 도구와 렌더러 버전, 입력·예산, 선택한 제작·재생 경로 및 차이·개입.
- 편집 가능한 원본, 전달 파일, 재현 진입점·명령, 수행한 검사와 로그 위치.
- 실제로 본 캡처/재생 근거와 사건 시각·카메라·사용 조건. 참고 이미지 자체를 최종 결과 근거로 쓰지 않습니다.
- 사용자 선호, 남은 시각적 결함, 여전히 필요한 구체적 미술 지도, 수정에서 관찰한 득실, 미검증 범위와 예산·도구 차단 요인.

시각적 선호, 기술적 유효성, 실제 청취와 측정한 실행 성능은 별개의 주장으로 유지합니다. 큐 예약이나 파형만으로 음질을 확인할 수 없고, 소프트웨어 렌더링은 대상 장치의 성능 근거가 아닙니다. 파일·보고서 개수와 완료된 캡처는 보조 근거이며 미술적 승인이 아닙니다. 검토 범위는 고정된 검토·이미지 횟수가 아니라 효과의 위험 요소에서 정하고, 빠진 근거는 미확인으로 남깁니다.

| 관찰한 원인 | 돌려줄 정보 |
| --- | --- |
| 지침이 없거나 모호함 | 어떤 결정에 안내가 부족했는지와 그 결과 |
| 지침은 있으나 적용하지 않음 | 해당 문구, 실제 행동과 차이 |
| 도구·환경·연동 문제 | 재현 명령, 버전, 오류와 가장 작은 실패 단계 |

여러 원인이 섞였거나 근거가 부족하면 그대로 표시합니다. 테스트 세션은 스킬을 자동 수정하지 않습니다. 작성 세션은 관찰한 실패에서 재사용 가능한 판단 기준을 추리되 한 샘플에 맞춘 정답이나 만점 평가표로 만들지 않습니다. 실제 제작·검토 기준은 [VFX 안내](VFX.md)를 따릅니다.

첫 비교에서 가능성이 보이면 조용한 지속 효과와 좁은 범위 수정으로 과잉 적용을 시험하고, 결과가 불확실한 경우 반복합니다. 조용한 효과의 의도한 연속성이 유지되는지, 작은 수정이 무관한 재설계로 번지지 않는지 확인합니다. 한 쌍의 비교는 방향을 탐색하는 근거이며 인과 증명이 아닙니다. 모델 전반에 관한 주장에는 추가 모델이 필요합니다. 재생·캡처 도구 개선은 스킬 문구와 별도로 비교한 뒤 개선 원인을 판단합니다. 표현·정확성·범위를 해치지 않는 유용한 개선 근거가 있는 변경을 유지하고, 뚜렷한 이득이 없으면 단순화하거나 재고합니다. 이는 앞으로 수행할 평가 절차이며 완료된 검증 기록이 아닙니다.

## 2026-10-07 혼합 제작 독립 테스트

스킬 `2e48363`에서 대화 이력을 상속하지 않은 에이전트에 새 얼음 늑대 투사체와 Three.js WebGL/Effekseer 미리보기라는 제품 요구를 전달했습니다. 기존 예제·제작 코드·검수 절차를 추가로 제공하지 않았습니다. 결과는 다음과 같습니다.

- 새 참조 이미지와 TRELLIS.2 메시를 만들고, Blender 처리 원본을 보존한 뒤 Three.js의 얼음 재질·파쇄와 Effekseer 보조 입자를 결합했습니다. 별도 Blender 조형 수정까지 시험한 것은 아닙니다.
- 에이전트가 요청한 다각도 화면을 보고 가는 궤적, 균일한 착탄 링, 서리를 가리는 큰 파편을 스스로 발견·수정했습니다. 수정 후 같은 사건과 각도, 밝은 배경, 가림 물체, 동시 3회, 접촉 직전·직후를 재검토했습니다.
- 브라우저 연결 장애 때문에 작성 세션이 에이전트가 지정한 원시 화면을 대신 캡처했습니다. 해결 방법이나 품질 피드백은 주지 않았으며, 이 환경 지원은 완전 무개입과 구분합니다.
- 실제 WebGL 로딩·재생 제어·시간 이동·재시작을 확인했습니다. 종료 시 활성 Effekseer 노드가 0이고 반복 실행의 계수가 같았지만, 이는 메모리 누수나 성능 보증이 아닙니다.

**판정:** 혼합 제작 선택과 자체 검토·수정 흐름을 확인했습니다. 소프트웨어 WebGL의 시점별 관찰이므로 정상 GPU 성능·정상 속도 연속 재생 품질은 미검증입니다. 평면에 저작된 접촉이며 임의 지형·다른 엔진은 범위 밖입니다. 별도 코드 검토에서 브라우저 이력 캐시 복귀 시 자원 수명 문제가 의심됐으나 재현은 완료되지 않았습니다. 생성물·개인 실행 기록은 저장소에 포함하지 않습니다. 이 사례를 새 평가 에이전트에게 정답으로 제공하지 않습니다.
