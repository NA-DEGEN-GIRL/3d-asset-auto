# 표면 결함 진단과 마감 절차 재사용

**한국어** | [English](FINISHING.en.md)

생성 결과를 다듬는 중 표면이 망가지거나, 성공한 마감 방법을 다른 에셋에 적용할 때 읽습니다. 아래는 사용자가 제공한 네크로맨서 작업 기록을 일반화한 판단 예시입니다. 모든 모델에 리메시·재베이크·가중치 이전을 적용하는 기본 파이프라인은 아닙니다. 필요한 처리는 LLM이 [Blender 편집 스크립트](BLENDER.md)로 작성하며, 자동 리토폴로지·재베이크 기능이 추가됐다는 뜻은 아닙니다.

## 처음 손상된 단계 찾기

보존된 **생성 원본 → 메시 정리·감면 → 리깅·가중치 적용 → 최종 출력** 중 실제로 존재하는 단계들을 같은 자세·카메라·조명에서 비교합니다. 텍스처가 없는 표시와 실제 재질 표시도 필요에 따라 비교해 형상·노멀·색상 문제를 구분합니다. 처음 결함이 보이는 출력과 바로 전 정상 입력을 찾아 처리 순서·설정을 검토합니다. 초기 단계에서 손상됐다면 마지막 결과를 반복 평활화하기보다 손상 전 입력에서 해당 처리를 다시 구성합니다.

| 관찰된 현상 | 원인 구분과 복구 판단 |
| --- | --- |
| GLB에서 경계 정점이 많지만 실루엣은 이어짐 | UV·노멀 표현을 위한 정점 분리인지 실제 틈인지 확인합니다. 필요하면 진단용 사본에서 모델 크기와 의도된 간극에 맞는 작은 거리로 정점을 묶어 연결성을 비교하고 사용한 거리도 기록합니다. 원본의 UV·노멀·별도 부품은 보존하며, 진단용 용접 결과를 바로 전달 메시로 쓰지 않습니다. |
| 감면 이후 조각난 표면·균열이 생김 | 분리된 표면 조각이 독립적으로 줄어들었는지 원본과 감면 직전·직후를 비교합니다. 실제 같은 표면으로 확인한 부분의 정리와 감면 순서를 검토합니다. 가까운 별도 부품·얇은 층을 일괄 용접하거나 닫지 않습니다. |
| 경계 수치가 남아 있어 본체에 구멍이 있다고 추정됨 | 경계가 어느 연결 성분에 속하는지 위치·크기·재질·실루엣과 함께 확인합니다. 본체의 열린 면, 의도된 개구부, 떠 있는 조각은 다른 문제입니다. 작은 성분도 장식이나 기능 부품일 수 있으므로 개수·크기만으로 삭제하지 않습니다. |
| 정지 형상은 괜찮지만 굽힘에서만 찌그러짐 | 표면 정리만 반복하지 말고 [골격·가중치·변형 단계](QUALITY.md#리그와-동작의-단계별-진단)를 비교합니다. 뼈 움직임과 실제 변형을 분리해 원인을 찾습니다. |
| Blender에서는 괜찮지만 GLB에서 달라짐 | 최종 GLB를 재가져와 노멀·재질·스킨·morph·보간과 출력에 반영된 보정 방식을 확인합니다. 소스의 정상 모습으로 출력 검사를 대신하지 않습니다. |

수치상 닫힌 메시인지 여부는 외관·의미·사용 가능성의 일부 증거입니다. 구멍이 의도된 형태에는 닫힘을 합격 기준으로 강제하지 않습니다.

## 복구 사례를 다음 작업에 적용하기

이번 기록에서는 감면된 표면의 단순 스무딩 대신 보존된 생성 메시로 돌아가 처리 순서를 바꿨습니다. 최종 경계를 다시 분류하면서 본체 구멍이라는 초기 추정을 외딴 조각 문제로 수정했습니다. 재사용할 것은 고정된 리메시 크기나 회전 제한이 아니라 **진단 → 선택한 처리 → 보존할 정보 → 확인 근거**입니다.

| 선택한 처리 | 다음 에셋에서 적용을 판단할 조건과 확인 |
| --- | --- |
| 손상 전 원본 복원 | 어느 입력이 마지막으로 정상인지 해시·처리 이력·동일 조건 렌더로 확인합니다. 기존 리그·동작·텍스처의 별도 원본도 남깁니다. |
| 표면 정리와 필요한 재구성 | 문제가 생긴 연결·감면 순서를 고칩니다. 리메시는 원래 표면 정리만으로 해결하기 어렵고 형상 변화가 허용될 때 선택하며, 얇은 부분·실루엣·장식·의도된 틈의 손실을 확인합니다. |
| 바뀐 표면으로 텍스처 이전 | 토폴로지·UV가 달라져 기존 텍스처를 그대로 쓸 수 없을 때 필요한 채널을 베이크합니다. 색상만 옮겼다고 노멀·거칠기 등까지 보존했다고 판단하지 않습니다. 투영 누락·다른 부품의 색상 번짐·이음새를 검사합니다. |
| 기존 스킨 가중치 이전 | 리그를 유지할 수 있을 때 확인된 표면 대응으로 가중치를 옮깁니다. 가까이 붙은 다른 팔다리·장비로 잘못 대응되지 않는지, 대응 거리·무가중 정점·영향 뼈를 보고 필요한 부분을 수정합니다. 토폴로지가 바뀌면 기존 morph도 그대로 유효하다고 가정하지 않습니다. |
| 관절 시험과 동작별 보정 | 사용할 굽힘·비틀림 범위를 먼저 확인하고, 각 동작의 접촉·변형·전환을 검토합니다. 공유 메시·가중치가 바뀌면 클립 데이터가 같아도 관련 동작을 다시 봅니다. |
| 최종 출력과 보존 확인 | 최종 GLB에서 필요한 형상·재질·동작을 확인하고 [클립 비교](BLENDER.md#개별-클립-수정과-보존-비교)로 변경 범위를 대조합니다. 처리 성공, 데이터 보존, 실제 품질은 따로 기록합니다. |

다시 활용할 로컬 작업 기록에는 입력·스크립트·출력의 경로/해시, 선택 이유, 모델 크기와 조건, 실제 매개변수, 실패한 시도와 복구 이유, 검토 범위·남은 한계를 간결하게 남깁니다. 다른 모델에서는 이 조건부터 대조해 필요한 단계만 선택합니다. 한 사례의 거리·해상도·폴리곤 수·각도·시도 횟수를 공통 기본값으로 옮기지 않습니다. 모델·렌더·원본 스크립트는 기존 로컬 보존 규칙을 따릅니다.
