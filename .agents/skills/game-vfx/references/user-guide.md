# game-vfx 사용 설명서

**한국어** | [English](user-guide.en.md)

`$game-vfx 설명서`라고 요청하면 가능한 작업, 도구 선택과 요청 예시를 짧게 안내합니다. 설명서 요청만으로 설치·생성·베이크·웹 미리보기나 유료 호출을 실행하지 않습니다. 제작도 함께 요청하면 설명 후 해당 작업을 이어갑니다.

## 무엇을 할 수 있나요?

불·얼음·번개·충격파·궤적·오라 같은 게임 효과를 만들거나 수정합니다. 형태, 움직임, 색·재질, 발생·충돌·소멸 시점을 설계하고 **실제 프로젝트의 렌더러에 맞춰** 셰이더·입자·메시·애니메이션을 조합합니다. 필요한 원본과 재생 코드를 보존하고, 효과별 주요 시점과 전환을 다각도로 검토합니다.

전용 AI VFX 모델 하나가 완성 효과를 자동 생성하는 시스템은 아닙니다. 제공된 불·얼음·번개 예제는 재사용할 출발점이며, 모든 효과나 상용 게임 수준의 품질을 보장하지 않습니다. 실제 지형 충돌·피해 판정·게임 이벤트 연결은 대상 프로젝트에서 별도로 구현하고 확인합니다.

## 어떤 도구와 모델을 쓰나요?

| 도구·경로 | 역할과 선택 기준 |
| --- | --- |
| 대상 프로젝트의 셰이더·입자·메시 시스템 | 기본 재생 경로입니다. 기존 효과 시스템, 렌더러·버전, 장치, 카메라와 상호작용에 맞춰 제작합니다. 엔진이 미정이면 임의로 고르지 않습니다. |
| Blender | 필요한 곡선·메시·노이즈 재료, 물체 애니메이션, 강체 운동과 베이크에 우선 활용하는 로컬 도구입니다. 모든 효과에서 반드시 실행하는 단계는 아닙니다. |
| 제공된 Blender helper + Three.js 예제 | helper는 3D 노이즈와 번개 경로를 만듭니다. 불은 공간 필드 셰이더, 얼음은 기존 파쇄 클립 재생, 번개는 경로와 방전 타이밍으로 구성됩니다. 완성된 세 효과가 GLB 하나에 들어가는 방식은 아닙니다. |
| Blender Mantaflow — 필요할 때 선택 | 기체·불·연기 또는 액체 시뮬레이션 재료를 만들 수 있습니다. 결과를 목표 재생 형식으로 변환하는 작업이 필요하며, 제공 helper에는 범용 유체 캐시 내보내기·재생 기능이 없습니다. 모든 화염탄에 시뮬레이션이 필요한 것은 아닙니다. |
| ImageGen / 사용이 승인된 Grok 영상 | 형태·색·재질·시간 흐름의 참고 자료, 또는 검토한 텍스처 재료에 활용합니다. 이미지·영상만으로 3D 유체·충돌·궤적이나 게임 효과가 자동 복원되지 않습니다. 사용 가능한 도구와 해당 작업의 권한 범위 안에서 선택합니다. |
| 별도 `3d-assets` 스킬 | 독립된 얼음 덩어리·운석 등의 모델이 필요할 때 연결합니다. 기존 메시를 재사용할 수 있고, 새 모델은 참조 이미지 → **TRELLIS.2**가 기본입니다. **Tripo는 사용자가 명시적으로 선택한 유료 옵션**입니다. 모델이 필요 없는 효과는 이 추론 경로가 필요 없습니다. |

VFX의 절차적 필드·리본·입자·번개 가지 제작은 정상적인 제작 방식입니다. 별도 독립 모델을 생성하는 `3d-assets`의 정책과 구분합니다. 사람 모션용 Kimodo는 일반 VFX 기본 도구가 아니며 명시적 선택이 필요합니다. Houdini·EmberGen 등은 기본 의존성이나 제공된 자동 어댑터가 아닙니다.

## 어떻게 요청하면 좋나요?

가능하면 **효과의 모습과 동작, 사용할 프로젝트, 길이·크기, 카메라 범위, 필요한 파일**을 알려 주세요. 모르는 항목은 생략해도 됩니다. 기존 파일이나 참고 이미지·영상이 있으면 함께 지정합니다.

| 원하는 작업 | 요청 예시 |
| --- | --- |
| 기능·도구 기억하기 | `$game-vfx 설명서. 기본 도구와 선택 옵션을 짧게 알려 줘.` |
| 현재 설치 상태 확인 | `$game-vfx 지금 이 실행 환경에서 쓸 수 있는 도구를 읽기 전용으로 확인해 줘. 설치나 생성은 하지 마.` |
| 기존 게임용 새 효과 | `$game-vfx 이 Godot 프로젝트에 1초짜리 푸른 번개 타격을 만들어 줘. 게임 카메라에서 가지와 착탄 시점이 잘 보여야 해.` |
| 출력 형식 지정 | `$game-vfx 3초짜리 푸른 화염 기둥을 GLB로만 전달해 줘. 여러 방향에서 볼 거야.` |
| 기존 모델 재사용 | `$game-vfx 이 운석 GLB로 낙하·충돌 효과를 만들고 현재 프로젝트에 연결해 줘.` |
| 특정 제작 방법 선택 | `$game-vfx Mantaflow로 연기 폭발을 베이크하고 이 프로젝트에서 재생되도록 변환해 줘.` |
| 설명과 제작을 함께 | `$game-vfx 쓸 도구를 간단히 설명하고, 이 프로젝트의 검 궤적을 더 선명하게 고쳐 줘.` |
| 웹 미리보기 요청 | `$game-vfx 만든 효과를 회전·재생하며 볼 수 있는 웹 미리보기도 열어 줘.` |

## 결과와 확인 범위

- **기본 결과:** 요청한 형식과 그 재생에 필요한 리소스, 편집 가능한 원본, 크기·좌표·시간·이벤트 설명 및 실제 검토 범위입니다. 엔진이 미정이어도 요청한 파일을 우선하며, 웹 미리보기는 요청한 경우에만 만듭니다.
- **GLB의 범위:** 메시와 지원되는 재질·애니메이션을 담을 수 있지만, 엔진 셰이더·입자 시스템·Blender 유체 캐시가 자동으로 포함되지는 않습니다. GLB만 요청하면 그 형식으로 가능한 표현을 설계합니다.
- **설치와 검증:** 이 설명서는 지원 경로를 안내하며 현재 PC에 모두 설치됐다는 뜻은 아닙니다. 현재 상태를 요청하면 `doctor`와 관련 리소스 계획 등을 읽기 전용으로 확인할 수 있습니다. 감지된 파일, 실제 실행 성공, 시각 품질, 대상 게임의 성능은 각각 구분해 보고합니다. 자격 증명이나 비공개 장치 식별자는 공개하지 않습니다.
- **출처와 라이선스:** 외부 모델·텍스처·영상·코드와 서비스 출력의 조건을 각각 확인하고 출처를 보존합니다. 도구가 무료이거나 설치되어 있다는 이유로 모든 결과의 재배포 권한이 보장되지는 않습니다.
