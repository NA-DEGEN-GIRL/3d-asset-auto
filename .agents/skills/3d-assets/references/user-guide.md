# 3d-assets 사용 설명서

**한국어** | [English](user-guide.en.md)

`$3d-assets 설명서`라고 요청하면 제작을 시작하지 않고 핵심 사용법을 안내합니다. `설명서 자세히`, `모델 종류만 알려줘`, `Kimodo 사용법`처럼 필요한 부분만 물어봐도 됩니다.

소품·건물·캐릭터를 생성하거나 기존 모델을 수정하고, 필요하면 리깅·애니메이션·부품 분리를 처리합니다. 기본 결과물은 **검토한 GLB와 Blender 원본**입니다. 여러 동작은 이름 있는 클립으로 한 GLB에 모읍니다.

## 어떤 모델·도구를 쓰나

| 하고 싶은 일 | 모델·도구 | 선택 방식과 역할 |
| --- | --- | --- |
| 새 3D 모델 생성 | **TRELLIS.2** | 기본. 단일 참조 이미지로 로컬 GPU에서 메시를 생성합니다. |
| 유료 3D 생성·멀티뷰 입력 | **Tripo / Tripo3D API** | **“Tripo로” 명시할 때** 선택. 설정된 키와 크레딧이 필요합니다. |
| 리깅 초안 | **SkinTokens** | 변형할 메시의 골격·가중치가 필요할 때 선택 설치합니다. 기존 리그나 Blender 저작도 활용합니다. |
| 사람 동작 생성 | **Kimodo-SOMA-RP-v1.1** | **“Kimodo로” 명시할 때** 로컬 문장 조건 모션을 생성합니다. 리깅된 인간형이 먼저 필요하며, 적용 후 Blender에서 다듬습니다. |
| 형태·재질·리그·동작 편집 | **Blender** | 기본 로컬 편집 도구. 사용자 동작, 기존 클립 수정·병합, 필요에 맞는 `idle`·`walk`·`run` 프리셋을 활용합니다. |
| 의미 있는 부품 분리 | **GeoSAM2** | 필요한 때 설치. LLM이 렌더를 보고 이름과 점을 지정하고 분리 결과를 검토합니다. |
| 형태·동작 참고 | 사용 가능한 **ImageGen**, 선택적 **Grok Imagine 영상** 등 | 이미지는 형태·자세, 영상은 순서·타이밍 참고입니다. 생성 영상에서 3D 동작을 자동 추출하는 기능은 없습니다. |
| 프로젝트·웹 검증 | **Godot / Three.js** | 대상 프로젝트에 필요한 검사, 또는 요청한 웹 미리보기에 사용합니다. 매 작업의 필수 단계가 아닙니다. |

위 표는 **지원하는 기능**입니다. 현재 호스트에 모두 설치됐거나 추론이 검증됐다는 뜻은 아닙니다. `지금 이 환경에서 사용 가능한 도구 확인해 줘`라고 요청하면 설치·실행 상태를 읽어서 구분해 줍니다.

## 기억할 기본값

- 새 메시: **참조 이미지 → TRELLIS.2 → Blender → 렌더 검토**. 텍스트 요청이면 사용 가능한 이미지 도구로 참조를 먼저 준비합니다. Blender 도형 조립으로 추론을 대체하지 않습니다.
- **Tripo와 Kimodo는 각각 명시적으로 선택**합니다. Tripo로 만든 모델이라고 Kimodo나 유료 Tripo 후처리를 자동 선택하지 않습니다. Kimodo는 메시 생성·리깅 도구가 아닙니다.
- 기존 모델 수정은 재생성이 필요하지 않습니다. 정적 소품에 리그를 붙이지 않으며, 절차적 새 메시 생성은 그 방식을 요청한 경우에 사용합니다.
- 기본 검수는 로컬 렌더입니다. 웹앱이 필요하면 **“웹에서 보여줘”**를 덧붙입니다. 설치·추론·수치 검사 성공과 실제 품질 합격은 별도입니다.
- 명시한 Tripo 요청은 에셋당 표준 생성 1회를 진행합니다. `max_credits` 기본값 100은 **로컬 예상 비용 가드**이며 서버 결제 한도나 무제한 재시도 승인이 아닙니다. 입력 이미지는 Tripo에 전송됩니다. [비용·키·복구 안내](../../../../docs/TRIPO.md).
- GPU 선택, CPU 스레드, 동시 Blender 작업 수는 실행 호스트의 **비공개 리소스 설정**을 따릅니다. 지정 자원이 바쁘면 대기하며 다른 GPU로 임의 전환하지 않습니다. [리소스 설정](../../../../docs/RESOURCES.md).

## 그대로 쓸 수 있는 요청

> `$3d-assets` 판타지 마을의 돌집을 만들어 줘. 렌더를 검토해서 GLB로 전달해 줘.

> `$3d-assets` Tripo로 이 정면·후면 이미지를 사용해서 방패를 만들어 줘.

> `$3d-assets` Tripo로 탐험가 캐릭터를 만들고 리깅한 뒤, Kimodo로 인사 동작을 만들어 줘. Blender에서 다듬고 웹에서 비교해서 보여줘.

> `$3d-assets` 기존 캐릭터의 공격 동작만 수정해 줘. 나머지 동작은 보존하고 모두 한 GLB로 전달해 줘.

> `$3d-assets` 지금 이 환경에서 사용 가능한 모델과 GPU·CPU 제한을 간단히 확인해 줘. 설치나 생성은 하지 마.

## 더 필요한 경우

설명서 요청은 자연어 대화이며 새 CLI 명령이 아닙니다. 자세한 실행은 [runtime.md](runtime.md), 요청 필드는 [specs.md](specs.md), 호스트 설치·연결은 [execution-setup.ko.md](execution-setup.ko.md)를 참고합니다.

Kimodo의 리그·보정 흐름은 [Kimodo 안내](../../../../docs/KIMODO.md), 수정·병합은 [Blender 안내](../../../../docs/BLENDER.md)에 있습니다. 불·번개 같은 게임 효과 자체는 별도 **`$game-vfx 설명서`**로 시작하고, 효과에 독립된 3D 모델이 필요할 때 이 스킬을 함께 사용합니다.
